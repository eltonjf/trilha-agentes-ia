Módulo 01

Fundamentos de LLMs e Engenharia de Prompt

Antes de criar agentes, você precisa dominar o motor que os impulsiona: os Large Language Models (LLMs). Aprenda sobre tokenização, janelas de contexto, alucinações e como moldar o comportamento do modelo programaticamente.

💡 O que você vai aprender na prática:

  • Configuração de ambiente com chaves de API (OpenAI / Anthropic / Groq).
  • Técnicas de Chain-of-Thought (Cadeia de Pensamento) para forçar o modelo a raciocinar antes de responder.
  • Uso de JSON Mode / Function Calling para saídas estruturadas em código.

Módulo 02

RAG (Retrieval-Augmented Generation)

O RAG resolve a maior limitação dos LLMs: dados desatualizados ou privados. Ele permite que o modelo consulte documentos internos da empresa (manuais, tabelas de preço, histórico) em tempo real antes de formular uma resposta.

⚙️ Pipeline Técnico do RAG:

Ingestão $\rightarrow$ Chunking $\rightarrow$ Embeddings $\rightarrow$ Vector DB $\rightarrow$ Geração Baseada no Contexto.

Módulo 03

Tipos de Agentes, Modelos (Claude Opus/Sonnet) & Frameworks (Fable/CrewAI)

Um Agente de IA não apenas responde, mas planeja, executa ações, utiliza ferramentas externas (APIs, calculadoras, SQL) e avalia seus próprios resultados através do ciclo Plan $\rightarrow$ Act $\rightarrow$ Observe.

Panorama de Modelos (Opus, Sonnet, GPT-4o)

Para dimensionar projetos, você deve escolher o modelo certo:

  • Claude 3 Opus (Anthropic): Altíssimo nível de raciocínio, excelente para arquiteturas complexas de agentes multi-etapas e código sofisticado.
  • Claude 3.5 Sonnet: Ótimo equilíbrio entre velocidade, custo e inteligência avançada (líder de mercado em engenharia).
  • GPT-4o / GPT-4o-mini: Rápidos, versáteis e ideais para chamadas multimodais em larga escala.

Padrões e Frameworks de Agentes

Frameworks modernos para estruturar múltiplos agentes:

  • CrewAI / AutoGen: Focados em equipes de agentes colaborativos com papéis definidos (ex: Pesquisador, Escritor).
  • LangGraph: Controle de fluxo determinístico em grafos, essencial para sistemas corporativos robustos.
  • Fable (e afins): Ambientes de simulação e frameworks de orquestração para cenários dinâmicos.

Vamos aplicar a engenharia de agentes no mundo real simulando uma solução completa para uma loja de móveis de médio porte.

Módulo 05

Dimensionamento de Custos, Hospedagem e Pitch Comercial

Para chegar em uma empresa e vender o seu projeto, você precisa saber calcular exatamente quanto custará rodar a IA e demonstrar o Retorno Sobre o Investimento (ROI).

Teoria de Dimensionamento e Custos de LLMs

Os custos de APIs de LLM são calculados por Tokens (aproximadamente 4 caracteres ou 0.75 palavras em inglês). Existem dois tipos de custos: Tokens de Entrada (Prompt) e Tokens de Saída (Completion).

Exemplo Prático de Cálculo (Claude 3.5 Sonnet / GPT-4o mini):

• Custo médio Input: $3.00 por 1 milhão de tokens (~R$ 15).

• Custo médio Output: $15.00 por 1 milhão de tokens (~R$ 75).

Se a loja de móveis faz 1.000 atendimentos/mês (média de 2.000 tokens por interação), o custo total de API será de ~$10 a $25/mês!

Infraestrutura & Hospedagem:

• Servidor VPS (DigitalOcean / AWS EC2): $20 - $40/mes para rodar o backend em Node.js/Python e o Vector DB.

• Modelos Locais (Ollama com Llama 3): Custo zero de API, mas requer servidor dedicado com GPU (ex: AWS g4dn.xlarge).

🚀 Hospedagem & Deploy

Containerização com Docker, deploy em servidores Linux, configuração de webhooks para WhatsApp (Evolution API ou Z-API) e monitoramento de logs.

💼 O Pitch Comercial

Apresente para o empresário: 1. Diagnóstico do gargalo $\rightarrow$ 2. Demonstração viva do agente $\rightarrow$ 3. ROI (economia de horas de equipe e aumento de vendas) $\rightarrow$ 4. Implementação em etapas.
